# AGENTS.md

A Motoko testing library, published to [Mops](https://mops.one/) as `test`, for writing and running tests with `mops test`.

## Build & test

This is a [Mops](https://docs.mops.one/) package. Install the Mops CLI, then:

- Install dependencies: `mops install`
- Run tests: `mops test`

CI (`.github/workflows/pull_request_build.yml`) runs only `mops test`; keep it green.

The project pins its toolchain in `mops.toml`:

- `moc` 1.0.0
- `wasmtime` 40.0.0
- `pocket-ic` 15.0.0

There is no configured lint or format step; match the existing style (tabs for indentation).

## Layout

- `src/` — library source (`lib.mo` is the sync entry, `async.mo` the async entry).
- `src/expect/` — the `expect` matchers, one file per type (`expect-nat.mo`, `expect-text.mo`, ...).
- `test/` — the package's own tests, as `*.test.mo` files; this is also the directory `mops test` discovers tests in.

## Conventions & gotchas

- Test files must be named `*.test.mo` and live in `test/`.
- `.mops/` is generated by `mops install` and is gitignored; never hand-edit it.
- Replica/actor tests must use an unnamed `persistent actor { ... }` exposing a `runTests` method (see `README.md`); `mops test` starts a local replica on port `4945` for these.
- Bump `version` in `mops.toml` and add an entry to `CHANGELOG.md` for user-facing changes.
