# AGENTS.md

Motoko testing library (`mo:test`) distributed via the Mops package manager.

## Build & test

- Run the test suite with `mops test`. This compiles and runs every `*.test.mo`
  file under `test/` and is the same command CI runs.
- The build depends on the Motoko compiler (`moc`) and `wasmtime`. If `moc` is
  missing, install it with `mops toolchain use moc latest`.
- Replica tests start a local replica and require `dfx`; CI uses dfx `0.30.1`.

Tool versions are pinned in `mops.toml` under `[toolchain]` and `[requirements]`
(`moc = 1.0.0`, `wasmtime = 40.0.0`). Match these when reproducing CI.

## Layout

- `src/` — library source. `src/lib.mo` and `src/async.mo` are the public
  entry points; `src/expect/` holds the `expect` matchers, one file per type.
- `test/` — the library's own test files (`*.test.mo`), which double as usage
  examples.

## Conventions

- Test files must live in `test/` and be named `*.test.mo` for `mops test` to
  discover them.
- Replica-style test files must define an unnamed `persistent actor { ... }`
  exposing a `runTests` method (see `README.md`).
- `.mops/` is generated by Mops (dependency cache); never hand-edit it. It is
  gitignored.
- Version in `mops.toml` and `CHANGELOG.md` are kept in sync on release.
