# AGENTS.md

A Motoko testing library (`mo:test`) that is installed and run with [Mops](https://mops.one).

## Build, test

- Run the test suite: `mops test` (this is what CI runs).
- Tests live in the `test/` directory as `*.test.mo` files.

## Toolchain

Tool versions are pinned in `mops.toml` under `[toolchain]` and `[requirements]`.
CI installs Mops via the `setup-mops` action and ensures `moc` is available with:

```
mops toolchain bin moc || mops toolchain use moc latest
```

Do not bump pinned versions unless the change explicitly requires it.

## Layout

- `src/` — library source. `src/lib.mo` is the entry point (`mo:test`); `src/async.mo` is
  `mo:test/async`. `src/expect/` holds the `expect` matchers.
- `test/` — the library's own tests.

## Conventions

- `.mops/` is generated by Mops (dependency cache) and is git-ignored; never hand-edit it.
- Replica/async tests that drive IC APIs must define an unnamed `persistent actor { ... }`
  exposing a `runTests` method (see `README.md`).
